# 英语阅读分区看板重构技术方案

> 状态：设计稿与实施方案已确认，功能代码待实现  
> 效果图版本：v1  
> 设计预览：[english-reading-dashboard-concept-v1.png](assets/english-reading-dashboard-concept-v1.png)

![英语阅读分区效果图](./assets/english-reading-dashboard-concept-v1.png)

## 1. 目标

在保留中控台全局侧栏、顶部栏和紫色主题的前提下，将英语阅读分区重构为数据密集但易读的学习看板：

- 默认进入“阅读概览”，集中展示成绩、错因和阅读词库。
- 年份成绩、错因分析、阅读词库继续保留独立详情页。
- “录入成绩”成为页面最醒目的主操作。
- 图表、表格和词卡全部来自已有真实记录，不填充演示数据。
- 复用现有精读原文、上下文查词、AI 拆句、语境卡复习和通用错题库联动。

## 2. 信息架构

英语阅读页调整为四个内部视图：

| 视图 | 用途 |
| --- | --- |
| `overview` | 默认概览，展示四项指标、三个核心面板和四个快捷入口 |
| `scores` | 完整年份/Text 成绩、作答历史和原文入口 |
| `analysis` | 成绩趋势、题型失分、能力弱项和干扰项分析 |
| `vocabulary` | 阅读词卡管理、筛选、手动补卡和复习队列 |

`readingSection` 增加 `overview` 并设为默认值。用户从概览进入详情后，保留原有返回、筛选和工作区行为。

## 3. 阅读概览

### 3.1 顶部区域

- 标题使用“阅读概览”，副标题说明统计范围为传统阅读 A 节。
- 右侧放置高对比紫色按钮“录入成绩”，带加号 Lucide 图标。
- “补录历史阅读”作为次要操作保留在顶部或底部快捷入口。

### 3.2 四张统计卡

| 指标 | 数据来源 | 展示规则 |
| --- | --- | --- |
| 完成篇数 | `projection.stats.completedPassages` | 统计已有首做记录的年份/Text |
| 平均正确率 | `projection.stats.averageFirstScore` | `平均分 ÷ 10 × 100%` |
| 平均耗时 | `projection.stats.averageDuration` | 按现有分钟精度格式化，零值显示“暂无记录” |
| 累计生词 | 所有 lexical sense | 主值为语境义总数，副值为已掌握数量 |

成绩和耗时卡可使用最近作答数据绘制迷你趋势线。没有足够数据时不绘图，只显示空状态。

### 3.3 年份成绩面板

- 支持“按年份趋势”和“按 Text 表现”切换。
- 年份趋势使用现有 SVG 折线图，并保留可展开的数据表。
- 最近成绩表固定展示最近 5 条有作答记录的篇目：

| 列 | 内容 |
| --- | --- |
| 年份 | 试卷年份 |
| Text | Text 1–4 |
| 首做正确率 / 耗时 | 首次作答成绩和时长 |
| 最近正确率 / 耗时 | 最新一次作答成绩和时长 |
| 进步 | 最新成绩减首做成绩 |

- 面板标题和底部“查看全部年份成绩”进入 `scores`。

### 3.4 错因分析面板

- 支持“题型分析、能力弱项、干扰项”三个维度。
- 使用 SVG 环形图展示前四项，其余归为“其他”；同时展示文本图例、数量和比例。
- 图表下方展示最多 5 条高频或最近错题：
  - 年份、Text、题号；
  - 题型；
  - 能力原因或干扰项；
  - “加入错题库”或“打开错题库”操作。
- 面板标题和底部“查看全部错因分析”进入 `analysis`。

### 3.5 阅读词库面板

- 提供“我的词卡、学习中、待复习”三个快捷筛选。
- 支持表达和语境义搜索。
- 概览展示最近存储的 3 张词卡：
  - 单词或短语；
  - 当前语境中的中文义；
  - 原句摘要；
  - 年份/Text 来源；
  - 已掌握、学习中或待复习状态。
- “新建词卡”进入 `vocabulary` 并聚焦手动补卡表单。
- 面板标题和底部“查看全部词卡”进入 `vocabulary`。

### 3.6 底部快捷入口

| 入口 | 行为 |
| --- | --- |
| 阅读原文库 | 进入年份成绩并定位到已保存原文的篇目 |
| 精读选词 | 打开最近使用的精读工作区；无原文时引导先录入 |
| AI 拆句辨析 | 打开精读工作区的选区解释能力；无选区时显示使用说明 |
| 补录历史任务 | 进入历史阅读任务补录列表 |

## 4. 成绩录入弹窗

继续使用 `#readingAttemptDialog`，但改造成更明显的大尺寸录入工作区。

### 4.1 视觉与布局

- 桌面宽度约 `1040px`，最大高度不超过视口。
- 顶部使用浅紫渐变标题区，明确显示“录入英语阅读成绩”。
- 内容划分为三个带编号的区域：
  1. 基本信息；
  2. 阅读原文；
  3. 逐题结果。
- 桌面使用双栏，手机端使用全屏单列。
- 底部操作栏保持吸附，主按钮文案为“保存成绩并更新分析”。

### 4.2 基本信息

- 年份；
- Text 1–4；
- 作答日期；
- 耗时；
- 是否限时。

### 4.3 逐题结果

- 根据 Text 自动显示对应的连续 5 道题。
- 每题直接显示“答对、答错、未作答”分段控件。
- 选择“答错”后展开：
  - 用户答案；
  - 正确答案；
  - 题型；
  - 能力原因；
  - 干扰项；
  - 备注。
- 错误提示显示在具体字段附近，并将键盘焦点移到第一个错误字段。

## 5. 响应式与无障碍

| 宽度 | 布局 |
| --- | --- |
| `≥ 1280px` | 四张指标卡；成绩、错因、词库三栏 |
| `768–1279px` | 两栏；词库面板跨两列 |
| `< 768px` | 全部单列；表格转卡片或使用局部安全横向滚动 |

通用要求：

- 页面本身不得产生横向滚动。
- 所有主要按钮和输入控件至少 `44px` 高。
- 使用 Lucide 图标，不使用 Emoji 作为结构图标。
- 图表必须提供文本图例或数据表，不以颜色作为唯一信息。
- 保留可见键盘焦点、合理阅读顺序、ARIA 标签和 `prefers-reduced-motion`。

## 6. 数据与兼容性

- 不新增 API 路径。
- 不改变英语阅读 v6 数据结构。
- 不迁移或重写历史成绩、错题、原文、标记和词卡。
- 概览数据由现有 `EnglishReadingCore.project()` 结果和规范化状态派生。
- 月度或趋势对比只有在真实记录充足时展示；否则使用“暂无对比数据”。
- 不引入新的运行时依赖，折线图和环形图继续使用原生 SVG。

## 7. 测试与验收

### 自动测试

- `overview` 成为默认阅读视图，原有三个详情视图仍可访问。
- 四项指标与已有状态投影一致。
- 最近成绩表正确计算首做、最新和进步值。
- 错因维度切换、比例和高频错题映射正确。
- 词卡筛选、搜索、状态与详情跳转正确。
- 录入弹窗保存五题状态，答错题必须填写合法详情。
- 旧数据标准化和现有精读、词卡、错题联动测试继续通过。

### 浏览器验收

- 检查 `375px`、`768px`、`1024px`、`1440px`。
- 点击“录入成绩”，确认弹窗显著、可滚动且保存按钮始终可见。
- 检查表格、折线图、环形图、空状态和详情跳转。
- 检查键盘操作、ARIA、焦点状态和减少动态效果。
