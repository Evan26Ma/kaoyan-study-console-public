# “导入错题”工作台重构

## 目标与边界

本次只重构中控台的“导入错题”内容区，保留现有侧边栏、顶部栏、紫色主题、错题数据结构和后台接口。视觉回归基准为 [`assets/wrong-question-import-reference.png`](assets/wrong-question-import-reference.png)，用于确定内容层级、双栏布局和紧凑的信息密度，不复制其独立白色导航。

支持浏览器本地读取 `.txt`、`.md` 和 `.markdown` 文件，最多 20,000 字符；文件内容只写入现有文本框，不上传服务器。不支持 PDF/Word 解析、图片 OCR，也不新增数据版本或迁移历史错题。“恢复队列”仅重新检测 `/api/ai/status` 并同步 `/api/ai/wrong-question-jobs`，不重启 Node 进程。

## 页面结构

页面从上到下分为五段：

1. 导入工作台：桌面按约 40/60 分栏；左侧输入文本，右侧以三列两行填写科目、标题、来源、知识点、错因、优先级和首次复盘日期。
2. 后台队列：以“排队中 → AI 整理 → 一图流生成 → 写入错题库 → 完成”显示每个任务的阶段。
3. 大观园收藏与导入去向：桌面约 57/43 双栏，平板和手机上下排列；去向区只保留待复盘、错题库两张统计卡。
4. 更多功能：只提供已有页面能完成的操作入口；宽屏单行 8 张，平板 4 列，手机 2 列或 1 列。

输入区支持手动输入、系统剪贴板读取、本地文本文件读取、清空和用独立一行 `---` 分题。实时显示字符数与预计题数；单次最多 30 道，总文本最多 20,000 字符。当前输入非空时，读取文件前必须确认替换；类型错误、超限或读取失败均保留原内容。

导入页提供 85% / 90% / 100% 三档页面级密度，默认 90%，写入 `uiState.wrongImportScale`。密度由页面尺寸变量实现，不使用 `transform` 或 `zoom`。

## 导入规则

- “AI 自动整理”默认开启。开启后复用现有后台队列。
- “生成一图流”默认沿用用户本地偏好；只有 AI 自动整理开启时参与后台任务。
- 关闭 AI 后不要求 API Key。每段原始文本直接按现有 `normalizeWrongQuestion`、重复检测和 `saveState` 逻辑创建基础错题卡。
- 基础卡的题干为原始文本，解析留空并提示可稍后使用 AI 编辑或重做解析；每道题仍创建首次复盘计划。
- 标题未填写时，从每段文本首个非空行生成；批量导入时追加序号以便区分。
- 剪贴板读取失败只显示错误提示，不修改输入框内容。

## 数据来源

- 服务状态：`GET /api/ai/status`
- AI 队列：`/api/ai/wrong-question-jobs`
- 大观园：现有 `/api/integrations/cxyonly/*`
- 待复盘统计：现有 `wrongQuestions[].reviews`
- 错题库统计：现有 `wrongQuestions`、`noteImages`、`knowledgePoints`、`source`

统计口径：

- 今日到期、逾期、明日到期、本周内均只计算未完成且未归档的下一轮复盘。
- 本月新增按 `createdAt` 的年月计算。
- 一图流数量按至少有一张 `noteImages` 的错题数计算。
- 知识点与来源数量按去重后的非空值计算。

## 响应式与可访问性

- 1024px 及以上：导入约 40/60 双栏；收藏与去向为 57/43。
- 768–1023px：导入表单保持双栏；收藏与统计改为上下排列。
- 767px 以下：输入和元数据改为单列。
- 375px：所有区域单列，队列阶段只在自身容器内横向滚动，页面不横向溢出。
- 主要按钮和表单控件至少 44px；图标使用 Lucide。
- 开关使用原生 checkbox、可见标签和 `aria-describedby`；队列状态同时提供文字和 `aria-label`，不只依赖颜色。
- 保留 `:focus-visible`，并在 `prefers-reduced-motion: reduce` 时关闭新增过渡。
